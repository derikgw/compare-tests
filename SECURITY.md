# Security Policy

## Supported versions

This project is early stage. Security fixes are currently targeted to:

- latest `main` branch

Older snapshots, tags, and forks may not receive fixes.

## Reporting a vulnerability

Please do not open public issues for suspected vulnerabilities.

Instead, contact maintainers privately with:

- a description of the issue
- impact and affected components
- reproduction steps or proof of concept
- suggested remediation (if available)

## Response expectations

- Initial acknowledgment target: within 5 business days
- Follow-up cadence: as fixes are validated and prepared
- Public disclosure: after fix availability, when practical

These targets are best-effort and may change as maintainership evolves.
